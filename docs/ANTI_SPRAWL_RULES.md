# Anti-Sprawl Rules

1. One concern has one owner document.
2. Durable policy belongs in `docs/`; active reasoning in `plans/ACTIVE/`; generated output in `artifacts/`.
3. Reusable templates remain in `plans/`, `logs/`, `evals/`, or `schemas/`.
4. Update an existing owner rather than creating a sibling summary.
5. Do not add ad hoc root notes, TODOs, architecture snapshots, or scratch files.
6. New top-level files/directories require `docs/REPO_MAP.md` authority or change control.
7. Retired/superseded documents name their successor and move to `archive/` when traceability warrants retention.
8. Existing donor docs may remain as reference evidence, but cannot compete with LateralLine governance authority.
