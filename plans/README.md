# Plans

Use this directory for explicit long-horizon execution plans.

## Rules
- every substantial multi-step task starts from `TEMPLATE_EXEC_PLAN.md`
- active plans belong in `plans/ACTIVE/`
- one substantial task has one primary active plan
- each active plan has a same-stem `.checkpoint.json` sidecar
- plans cite governing docs, evidence, checkpoints, validation, and stop conditions
- completed or abandoned plans are marked clearly and moved to `archive/` when appropriate
