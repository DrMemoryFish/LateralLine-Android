# Active Plans

Put active multi-step execution plans here.

## Naming Convention
`YYYY-MM-DD_short-task-name.md`

Sidecar checkpoint manifest:
`YYYY-MM-DD_short-task-name.checkpoint.json`

## Rules
- one primary active plan per substantial task
- keep status and next action current
- keep the checkpoint manifest aligned with real file scope
- if a plan becomes obsolete, mark it and point to its replacement
