# Logs

This directory holds reusable entry templates. Authoritative project records live in `docs/DECISION_LOG.md`, `docs/FAILURE_LOG.md`, `docs/PROGRESS_LOG.md`, `docs/OPEN_QUESTIONS.md`, and `docs/RISK_REGISTER.md`.

Do not overwrite these reusable schemas with real entries. Copy a template shape into the matching authoritative record section.
